## 概要

ZipMania は、アーカイブを開いて作ることに集中したアーカイバーです。ZIP・RAR・7Z・EGG・ALZ・ISO をはじめ 50 種類以上の形式を開き、圧縮は **7Z · ZIP · TAR** の 3 種類で作成します。

アーカイブを開くと、左にフォルダーツリー、右にファイル一覧が表示されます。必要なファイルだけを選んで展開したり、エクスプローラーへドラッグしたりでき、画像は展開せずにそのままプレビューできます。ファイルをダブルクリックすると関連付けられたプログラムで開き、アーカイブの中のアーカイブは新しいウィンドウで開きます。

エクスプローラーの右クリックメニューから「ここに展開」「*名前*.zip に圧縮」のようなワンクリック操作が使え、自動バックアップや Total Commander などの外部プログラムから使えるコマンドラインツール（`zm.exe`）も含まれています。広告やバンドルソフトはありません。

## 主な機能

- **50 種類以上の形式を開く** — ZIP, ZIPX, JAR, RAR, 7Z, EGG, ALZ, TAR, GZ, BZ2, XZ, ZST, ISO, IMG, WIM, DMG, MSI, RPM, DEB, CAB, CBZ, CBR など。
- **7Z · ZIP · TAR に圧縮** — 圧縮レベル 5 段階、パスワード、7Z のファイル名暗号化、分割圧縮。
- **高速な ZIP 処理** — ZIP 専用エンジンが圧縮・展開を処理します。
- **必要なものだけ** — 一覧で選んだファイルだけを展開、エクスプローラーへドラッグ、ダブルクリックで直接開く。
- **アーカイブの中のアーカイブ** — ダブルクリックで新しいウィンドウに開きます。
- **画像プレビュー** — JPG, PNG, GIF, WebP, SVG などを展開せずに左下で確認できます。
- **アーカイブの編集** — 7Z · ZIP · TAR にファイルを追加・削除できます。
- **エラーチェック · セキュリティスキャン** — 破損の有無（CRC）を表で示し、Windows のウイルス対策（AMSI）で内部ファイルを検査します。
- **圧縮後の後片付け** — 圧縮が終わったら整合性を検査し、合格したときだけ元ファイルを削除します。
- **エクスプローラー右クリックメニュー** — ここに展開、*名前* に展開、*名前*.zip に圧縮、それぞれ圧縮、それぞれのフォルダーに展開。
- **コマンドラインツール** — `zm.exe`（コンソール）と `ZipMania.exe`（進行ウィンドウ）で圧縮・展開・一覧・検査。7-Zip 形式と Bandizip 形式のオプション表記を両方受け付けます。
- **ダーク／ライトテーマ、9 言語** — 既定では Windows の設定に従い、自分で選ぶこともできます。

## 使い方

### はじめての使い方

**展開する**

1. アーカイブをダブルクリックするか、ZipMania を起動して **[開く]** で選ぶか、ウィンドウにドロップします。
2. 左のフォルダーツリーと右のファイル一覧で内容を確認します。ファイルを選んで **[展開]** を押します。
3. **展開**ウィンドウで展開先フォルダーを選びます。左のクイックリンク（デスクトップ・ドキュメント・ダウンロードなど）やフォルダーツリーを使い、空いた場所を右クリックして新しいフォルダーを作ることもできます。
4. **展開するファイル**を**すべてのファイル** / **選択したファイル**から選び、**[OK]** を押します。進行率・速度・残り時間が表示され、終わったら **[フォルダーを開く]** で結果をすぐ確認できます。

**圧縮する**

1. ツールバーの **[新しいアーカイブ]** を押すか、ファイルやフォルダーを ZipMania のウィンドウにドロップします。
2. **新しいアーカイブ**ウィンドウにファイル一覧が入ります。**[ファイルを追加]** / **[フォルダーを追加]** で追加するか、ウィンドウにドロップします。
3. **ファイル名**（保存先）、**形式**（7Z · ZIP · TAR）、必要なら**パスワードを設定**、**分割**、**圧縮後**の動作、**圧縮方法**を決めます。
4. **[開始]** を押します。終わったら **[フォルダーを開く]** または **[閉じる]**。

エクスプローラーから直接行うには右クリックメニューを使います — 下の「こんなときは」を参照してください。

### 画面構成

| ツールバーのボタン | 役割 |
|---|---|
| **開く** | アーカイブを開く |
| **展開** | 開いているアーカイブを展開（ファイルを選んでいればそれだけを展開できる） |
| **新しいアーカイブ** | ファイル・フォルダーを選んで新しいアーカイブを作る |
| **ファイルを追加** / **ファイルを削除** | 開いているアーカイブにファイルを入れる・取り除く（7Z · ZIP · TAR のみ） |
| **検証** | アーカイブが壊れていないか検査（CRC） |
| **スキャン** | Windows のウイルス対策で内部ファイルを検査（10 MB 未満のファイル） |
| **フラット表示** | フォルダー構造を無視して全ファイルをパス付きの一覧で表示 |
| **設定** | テーマ・言語・展開の既定値・ファイルの関連付け・エクスプローラーメニュー |

- **左上のフォルダーツリー** — クリックするとそのフォルダーのファイルが右に表示されます。
- **左下のプレビュー** — 画像ファイルを 1 つ選ぶと表示されます。
- **ファイル一覧** — 名前 · サイズ · 圧縮サイズ · 種類 · 更新日時。名前・サイズ・更新日時の見出しをクリックすると並べ替え、境界をドラッグすると列幅を調整できます。
- **ステータスバー** — 項目数、選択したファイルの数とサイズ、圧縮サイズと圧縮率。
- 中央の境界をドラッグするとツリーと一覧の幅を変えられます。ウィンドウのサイズと最大化状態は次回起動時に復元されます。

### こんなときは

**エクスプローラーから直接展開する**
アーカイブを右クリックすると ZipMania のメニューが表示されます。
- **ここに展開** — 確認なしでアーカイブのあるフォルダーにそのまま展開します。進行ウィンドウで**ウィンドウを閉じる**をオンにしておくと、終わるとすぐ閉じます。
- **"名前" に展開** — アーカイブと同じ名前の新しいフォルダーを作り、その中に展開します。ファイルの多いアーカイブに向いています。
- **ZipMania で展開…** — 展開先とオプションを選ぶウィンドウが開きます。
- **ZipMania で開く** — まず中身を確認します。

アーカイブを**複数選んで**右クリックすると、**ここに展開**は順番に展開し、**それぞれのフォルダーに展開**はアーカイブごとに自分の名前のフォルダーに展開します。

**エクスプローラーから直接圧縮する**
ファイルやフォルダーを右クリックします。
- **"名前.zip" に圧縮** — 確認なしでその場に ZIP を作ります。フォルダー 1 つならそのフォルダー名、複数なら現在のフォルダー名がファイル名になります。同じ名前があれば `名前 (2).zip` のように番号が付きます。
- **ZipMania で圧縮** — 形式・パスワード・分割などを選ぶウィンドウが開きます。
- **それぞれ圧縮** — 選んだ項目ごとに自分の名前の ZIP を 1 つずつ作ります。複数のフォルダーを別々に保管したいときに使います。

**アーカイブから必要なファイルを数個だけ取り出す**
方法は 3 つあります。
- ファイルを選び（Ctrl・Shift で複数）、**[展開]** → **展開するファイル**で**選択したファイル**。
- 選んだファイルを右クリック → **選択したファイルを展開**。
- 選んだファイルを**エクスプローラーやデスクトップへドラッグ** — その場にすぐ展開されます。

**アーカイブ内のファイルを展開せずに直接開く**
ファイルをダブルクリックするか Enter を押すと、関連付けられたプログラムで開きます（文書はエディター、動画はプレーヤー）。右クリック → **ファイルを実行**も同じです。一時的に展開したファイルは ZipMania を閉じるときに片付けられます。

**アーカイブの中にさらにアーカイブがあるとき**
そのファイルをダブルクリックすると**新しいウィンドウ**で開きます。複数のウィンドウを開いたまま行き来できます。

**アーカイブ内の写真をすばやく眺める**
画像ファイル（JPG · PNG · GIF · BMP · WebP · ICO · SVG · TIFF · AVIF）を 1 つ選ぶと左下にプレビューが表示されます。矢印キーで下に移動しながら順に見られます。32 MB を超える画像はプレビューの代わりに案内が表示されます。

**フォルダーが深くてファイルを探しにくいとき**
ツールバーの **[フラット表示]** をオンにすると、フォルダー構造をなくして全ファイルをパス付きの一覧で表示します。名前・サイズ・更新日時で並べ替えれば、大きなファイルや最近のファイルがすぐ見つかります。もう一度押すとフォルダー表示に戻ります。

**パスワード付きのアーカイブ**
開くときにパスワード入力が表示されます。間違えると再度尋ね、合っていればそのアーカイブについて記憶するので、プレビュー・実行・展開で再び尋ねません。展開の途中でパスワードが必要なファイルが出てきたらそのときに尋ね、入力しなければそのファイルだけをスキップして残りを続けます。

**パスワードを付けて圧縮する**
**新しいアーカイブ**ウィンドウで **[パスワードを設定]** を押して入力します。
- **7Z** を選ぶと**ファイル名も暗号化**をオンにできます。パスワードなしでは中にどんなファイルがあるかも見えません。
- **ZIP** は英数字のパスワードだけ使えます。非 ASCII のパスワードは警告が出て開始されません — 7Z に変えるか英数字のパスワードを使ってください。
- **TAR** はパスワードに対応していません。

**大きなファイルをメールやメッセンジャーで送りたい**
**分割**で 10 MB · 25 MB · 100 MB · 700 MB · 1 GB · 4 GB を選ぶか、**カスタム…**に `700M`、`4GB` のように入力します。`名前.7z.001`、`.002`… に分かれて保存されます（7Z · ZIP）。受け取る側は断片を 1 つのフォルダーに集めて **`.001` ファイルだけ**を開くか展開すれば済みます。

**圧縮した後に元ファイルを消して空きを確保する**
**圧縮後**で**アーカイブを検証**と**元ファイルを削除**をオンにします。すべてのファイルが漏れなく格納され、検証まで通ったときだけ元ファイルを削除するので、圧縮に失敗したまま元ファイルが消えることはありません。

**複数のフォルダーをそれぞれ別々に圧縮する**
**新しいアーカイブ**ウィンドウにフォルダーを入れ、**各項目を個別のアーカイブに圧縮**をオンにします。フォルダーごとに自分の名前のアーカイブがその場所に作られます。エクスプローラーの右クリック → **それぞれ圧縮**と同じ動作で、ウィンドウでは形式とパスワードまで選べます。

**速く / 小さく圧縮する**
**圧縮方法**は**格納（圧縮なし）** · **高速** · **標準** · **高** · **最大**の 5 段階です。すでに圧縮済みの写真や動画をまとめるだけなら**格納**が最も速く、文書やソースコードのようによく縮むファイルは**高**や**最大**が有利です。最も小さくしたいなら形式は **7Z** を使ってください（既定値）。

**作成済みのアーカイブにファイルを入れる・取り除く**
7Z · ZIP · TAR のアーカイブを開いた状態で:
- **[ファイルを追加]** を押すか、ファイルをウィンドウにドロップします — 「N 個のファイルを … に追加しますか？」に「はい」。
- ファイルを選んで **[ファイルを削除]** または右クリック → **ファイルを削除**。
その他の形式（RAR, EGG など）は編集できないため、ボタンは無効になります。

**受け取ったアーカイブが壊れていないか確認する**
**[検証]** を押すと、ファイルごとに期待 CRC と実際の CRC を比較して表で示します。転送中に壊れたり一部しか受信できなかったファイルを、展開する前に見つけられます。

**受け取ったアーカイブが安全か確認する**
**[スキャン]** は展開せずに内部ファイルを Windows のウイルス対策（AMSI）に渡して検査します。10 MB 以上のファイルはスキップし、リアルタイム保護が有効なウイルス対策が必要です。結果はファイルごとに正常 · 脅威 · スキップで表示されます。

**展開時に同じ名前のファイルがすでにあるとき**
ファイルごとに**上書き** · **スキップ** · **名前を変更**を尋ねます。**残りのすべてのファイルに適用**をオンにすると、残りのファイルに同じ選択が適用されます。

**展開したらファイルがフォルダーに散らばってしまった**
既定で**アーカイブ名のサブフォルダーを作成**がオンになっており、アーカイブ名のフォルダーの中に展開されます。フォルダーなしで直接展開したいときは、**展開**ウィンドウか**設定 → 展開**でオフにするか、エクスプローラーの**ここに展開**を使ってください。

**展開したらアーカイブは削除し、フォルダーは開くようにする**
**設定 → 展開**で**展開に成功したらアーカイブを削除**、**展開先フォルダーを開く**、**展開ウィンドウを閉じる**をオンにします。展開ウィンドウでもその都度変えられます。アーカイブの削除は展開が成功したときだけ実行されます。

**アーカイブをダブルクリックで ZipMania で開くようにする**
**設定 → ファイルの関連付け**で拡張子にチェックを入れます。他のプログラムがすでにその拡張子を使っている場合は **[未適用]** と表示されるので、クリックすると Windows の既定のアプリ選択画面が開き、ZipMania に変更できます。ZipMania でアーカイブを開いたときに画面上部に「… ファイルの既定のアプリを ZipMania にしますか？」と表示されたら、そこで変更しても構いません。

**右クリックメニューに ZipMania が表示されないとき**
**設定 → エクスプローラーメニュー**で**エクスプローラーの右クリックメニューに ZipMania の圧縮/展開を追加**をオンにします。Windows 11 では標準メニューに表示されます。表示されない場合は**その他のオプションを表示**（Shift+F10）の下を確認してください。

**アーカイブのあるフォルダーを開く / アーカイブを削除する**
一覧の空いた場所を右クリックすると、**アーカイブのあるフォルダーを開く**と**アーカイブを削除**があります。内容を確認したあと、不要なアーカイブをその場で削除できます。

**一覧をキーボードで操作する**
矢印キー · Page Up/Down · Home/End で移動、Shift で範囲選択、Ctrl クリックで 1 つずつ追加、**Ctrl+A** で全選択、Enter でフォルダーに入る・ファイルを開く、Esc でパスワード・検査ダイアログを閉じる。

**ダークモードと言語**
既定では Windows の設定に従います。**設定 → 全般**でテーマ（システム · ライト · ダーク）と言語（한국어 · English · 日本語 · 中文 · Русский · Italiano · Français · Español · العربية）を選べ、変更はすぐに反映されます。エクスプローラーメニューの文言も同じ言語になります。

**自動バックアップスクリプトや Total Commander で使う**
実行ファイルを 2 つ使います。
- **`zm.exe`** — コンソールに出力します。cmd · PowerShell · バッチファイルは終了まで待ち、終了コード（0 成功 / 1 警告 / 2 エラー）を受け取ります。
- **`ZipMania.exe`** — 同じコマンドを**進行ウィンドウ**で表示します。Total Commander のようにコンソールのない場所に向いています。

```
<exe> a|c [オプション] <アーカイブ> <入力...>    圧縮（a は既存のアーカイブに追加）
<exe> x|e [オプション] <アーカイブ> [項目...]    展開（x はフォルダー構造を維持、e はファイルのみ）
<exe> bx  [オプション] <アーカイブ...>           アーカイブごとに自分の名前のフォルダーに展開
<exe> l   [オプション] <アーカイブ>              一覧
<exe> t   [オプション] <アーカイブ>              整合性検査
```

| オプション | 意味 |
|---|---|
| `-l:0..9` / `-mx9` | 圧縮レベル |
| `-fmt:zip\|7z\|tar` / `-t7z` | 形式（省略時は拡張子から） |
| `-v:700M` / `-v700m` | 分割サイズ |
| `-p:パスワード` / `-pパスワード` | パスワード |
| `-o:フォルダー` / `-oフォルダー` | 展開先フォルダー |
| `-target:auto\|name\|none` | アーカイブ名のサブフォルダーに展開（`auto` = 最上位項目が 2 つ以上のときだけ） |
| `-aoa` `-y` / `-aos` / `-aou` | 同じ名前があれば上書き / スキップ / `名前 (2)` として保存 |
| `-testdst` | 圧縮後に整合性検査 |
| `-delsrc` / `-sdel` | 検査に合格したら元ファイルを削除 |
| `-date` | ファイル名の `%Y %y %m %d %H %M %S` を現在時刻に置き換え |

例:

```
zm c -l:9 -fmt:7z -testdst -delsrc -date "backup_%y%m%d_%H%M.7z" "D:\Work"   日付名の 7Z にバックアップ、検査後に元ファイルを削除
zm a -mx9 -psecret backup.7z D:\Work                                       7-Zip 表記、既存のアーカイブに追加
zm x -o:D:\Out -target:auto backup.7z                                      アーカイブ名のフォルダーに展開
zm bx a.zip b.7z                                                            それぞれ a\、b\ フォルダーに展開
zm l backup.7z.001                                                          分割の最初の断片を一覧表示
```

`zm` だけを入力するとヘルプが表示されます。バッチファイルの中では `%` を `%%` と書きます。Total Commander のユーザーコマンドは、コマンドに `zm.exe`、パラメーターに `c -l:9 -fmt:7z -aou -testdst -delsrc -date "%T%S %y%m%d_%H%M".7z "%P%S"` のように設定すると、選択した項目を反対側のパネルのフォルダーに日付名の 7Z として圧縮します。

## 設定

**設定**（ツールバーの右端）で変更し、変更はすぐに保存されます。**[リセット]** ですべてを既定値に戻せます。

| 分類 | 項目 | 既定値 |
|---|---|---|
| 全般 | テーマ（システム · ライト · ダーク） | システム |
| 全般 | 言語（システム + 9 言語） | システム |
| 展開 | アーカイブ名のサブフォルダーを作成 | オン |
| 展開 | 展開に成功したらアーカイブを削除 | オフ |
| 展開 | 展開後に展開先フォルダーを開く | オフ |
| 展開 | 展開後に展開ウィンドウを閉じる | オフ |
| ファイルの関連付け | ダブルクリックで ZipMania で開く拡張子（zip · 7z · rar · tar · gz · tgz · bz2 · xz · egg · alz · cbz） | インストール時に関連付け |
| エクスプローラーメニュー | エクスプローラーの右クリックメニューに ZipMania の圧縮/展開を追加 | インストール時にオン |

新しいアーカイブウィンドウと展開ウィンドウの**ウィンドウを閉じる** · **フォルダーを開く**のチェックは、最後の選択が記憶されます。

## 動作環境

- Windows 10 または Windows 11、**64 ビット**
- 追加のランタイムやコンポーネントのインストールは不要です。
- インターネットは新しいバージョンの案内を確認するときにだけ使います。圧縮・展開はオフラインでも動作します。

## 更新

ZipMania は自動更新を**行いません**。起動時に新しいバージョンがあるか確認して案内するだけで、新しいバージョンは内部検証を経て手動で配布され、[ZipMania ページ](https://kilho.net/zipmania)で告知されます。[更新ポリシーのお知らせ](https://en.kilho.net/archives/notice/2940)もご覧ください。

## ソースからのビルド

ソースは [github.com/newkilho/ZipMania](https://github.com/newkilho/ZipMania) で公開されています（Rust 1.88 以上）。圧縮・展開エンジンの `crates/zipmania-archive` はリポジトリだけでビルドとテストができます。

```
cargo test -p zipmania-archive
```

アプリ画面（`app/`）はリポジトリ外の自社製画面エンジンと共用ライブラリに依存するため、リポジトリだけでは実行ファイルは作れません。
